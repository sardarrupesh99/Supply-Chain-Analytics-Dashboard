# Samsung Supply Chain & Logistics Analytics Dashboard

## 📊 Project Overview

This project presents an interactive **Supply Chain & Logistics Analytics Dashboard** developed using Power BI.

The dashboard provides a comprehensive view of supply chain performance by analyzing **suppliers, inventory, shipments, customers, revenue, profitability, and delivery performance**.

The main objective of this project is to transform raw supply chain data into meaningful business insights that can help organizations monitor operational performance and make data-driven decisions.

---

## 🎯 Project Objectives

* Analyze overall supply chain performance
* Monitor revenue and profitability
* Analyze supplier performance and lead time
* Track inventory levels and product stock
* Monitor shipment and delivery quantities
* Identify carriers with higher shipment delays
* Analyze customer/platform-wise revenue
* Monitor Perfect Order performance
* Create an interactive and user-friendly dashboard

## 📈 Dashboard Analysis

### 1. Supplier Analysis

Analyzes supplier performance based on average lead time and helps identify suppliers with better operational efficiency.

### 2. Inventory Analysis

Provides product-level inventory information and helps identify products with higher stock levels.

### 3. Shipment Analysis

Analyzes shipment quantities and identifies carriers responsible for higher shipment delays.

### 4. Customer & Revenue Analysis

Compares revenue generated through different customer platforms and identifies the highest-revenue platforms.

### 5. Financial Analysis

Provides an overview of total revenue, total profit, profit margin, and overall financial performance.
