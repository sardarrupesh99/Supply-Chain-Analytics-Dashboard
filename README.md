# Supply-Chain-Analytics-Dashboard
Developed an interactive Supply Chain Analytics Dashboard to monitor and analyze key supply chain operations, including inventory, orders, suppliers, shipments, and sales performance. The dashboard provides real-time insights to help improve operational efficiency, reduce costs, and support data-driven decision-making.
